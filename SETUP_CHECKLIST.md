# GitHub profile setup

## 1. Create the special profile repository
- [ ] Create a **public** repository named exactly `ramitl25727-cyber`.
- [ ] Do not initialize it with a README if you plan to push this bundle's README.
- [ ] Keep the repository's default branch as `main`.

## 2. Push the files
Copy `README.md`, `assets/`, and `.github/` into the repository root, then run:

```bash
git init -b main
git remote add origin https://github.com/ramitl25727-cyber/ramitl25727-cyber.git
git add .
git commit -m "chore: set up developer profile"
git push -u origin main
```
